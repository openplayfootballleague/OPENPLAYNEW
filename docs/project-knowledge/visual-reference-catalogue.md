# Open Play — Visual Reference Catalogue

**Status:** visual source images located in the ChatGPT Library; binary image files are not yet committed to this repository. This catalogue documents the source assets so they can be added without confusing mockups with the final implementation.

## How to use these references
- Treat the latest owner-approved screenshot for a given screen as the visual direction, not as authority to copy outdated labels, sample names, sample dates, stats or navigation.
- The functional rules in the product/workflow specifications take precedence over illustrative mockup data.
- Do not recreate or approximate the official OP logo. Use the original asset.
- Before replacing a visual direction, obtain owner approval.
- When image files are added to this directory, embed them below with relative Markdown image links and retain the original source filename in the caption.

## Important visual decisions
- Dark/black interface with Open Play orange accents.
- Oswald headings and Inter body/interface typography.
- Cinematic football imagery, restrained green pitch accents where appropriate, clear dark cards and strong hierarchy.
- The approved mobile bottom navigation is exactly four tabs: Home, Match Centre, Join Open Play, More. Some older screenshots show five tabs or different labels; those are superseded.
- Use current approved product names and workflows, not sample names or dates shown in mockups.
- The official logo is an owner-supplied asset and must never be redrawn.
